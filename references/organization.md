# Organization principles

Design inspiration comes from Marie Kondo’s The Life-Changing Magic of Tidying Up, Hideko Yamashita’s Danshari and 主妇之友社《家庭收纳1000例》. The principles below describe this project’s design.

- The player judges personal value, progress, completion and backlog.
- Put frequently edited lists first with the stable eight `00-` slots. Create them empty. The player maintains them in Steam.
- Keep library clutter away from active choices through player-managed collections. Game visibility and licenses stay under the player’s direct control.
- Give each classified game one primary gameplay location. Use series and themes as cross-references.
- Choose the compact preset if a smaller number of groups is easier to browse. Use overlap warnings to inspect redundant groups.
- Preserve approved classifications and review additions incrementally. A missing row is a change to inspect.

The player makes the decisions, deterministic tools handle repetition, and optional AI review helps interpret ambiguous public facts.
